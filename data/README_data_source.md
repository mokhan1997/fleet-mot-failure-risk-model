# Data Source

## Dataset Name

Anonymised MOT Tests and Results

## Source

Official UK Government / DVSA open data published via data.gov.uk.

Dataset page: Anonymised MOT tests and results

- MOT testing data results (2024)

## Purpose of Dataset

This dataset will be used to analyse MOT test outcomes and vehicle failure risk.

The project will explore:

- MOT pass/fail outcomes
- Vehicle age patterns
- Odometer/mileage patterns
- Make and model failure patterns
- Fuel type and vehicle class differences
- MOT failure risk indicators
- Fleet maintenance and vehicle reliability insights

## Why Raw Data Is Not Uploaded

The raw MOT CSV files are not uploaded to this GitHub repository because they are large external data files.

Users should download the dataset directly from the official data source and place the extracted files inside:

```text
data/raw/
```
